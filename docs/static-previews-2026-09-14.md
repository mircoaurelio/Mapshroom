# Static shader previews and studio cleanup

The preset library and shader timeline share static 128 × 128 WebP thumbnails on one flat square with a luminance gradient. Changing the stage asset no longer rebuilds thumbnails, and hovering a preset no longer changes or animates the stage. Explicit selection and timeline playback retain their existing behavior.

The packaged catalogue contains 777 presets backed by 763 unique images (2,547,914 bytes total). Identical shader code and effective uniform values share an image. Images load lazily and require no browser shader compilation. A representative frame is rendered at 1.6 seconds during generation; very dark presets retry at 3.2 and 5.6 seconds. WebP quality is 0.68. Regenerate with `npm run generate:thumbnails` after changing bundled presets; this requires Chrome, optionally selected with `CHROME_BIN`. Generation prunes obsolete images only after the complete replacement catalogue succeeds. Cache version 2 invalidates the previous sphere previews.

Custom shaders produce one frame per code/uniform combination on the same swatch. Generation is deferred until a card approaches the visible area, debounced during editing, serialized and shared across cards. Hidden/offscreen requests are deferred or cancelled. A bounded memory/CacheStorage cache holds up to 128 snapshots; the temporary WebGL renderer is released when the queue empties. Disabled storage falls back to session caching. Pending snapshots and image downloads show a small CSS loading icon until the actual image has loaded. Failed rendering or image loading shows a static unavailable icon; it never leaves a permanent spinner or a decorative radial placeholder. Reduced-motion preferences disable spinner animation.

The desktop chat, code and version history occupy the right sidebar in the upper workspace row. That column ends above the timeline, which spans the full width beneath both sidebars and the stage. The left sidebar retains sliders and asset controls. The existing mobile Shader drawer retains its compact prompt. There is no Shader Studio heading, manual Save control, suggestion tags or input-filling suggestion logic. Code starts collapsed and mounts the editor only when expanded; project autosave remains available. The desktop header exposes Projects through File and no longer duplicates the Projects button, its save-status badge or the Download/install button. Autosave status and retry remain in the Projects dialog.

The desktop timeline fills the complete workspace width below the stage and both sidebars. Its sole header contains previous/repeat/next, mode/count/duration, hold, transition settings and mode choices. The old position and segment rails, boundary/transition dragging, marker jumps and total-length scaling handlers have been removed, including their styles and listeners. The card highlight clock updates at 8 Hz while visible instead of a scrubber animation loop. Cards use square previews and plain text names, with no shader picker or redundant Shader label. Card sizes respond to the available height beneath the toolbar and the timeline width using CSS container units, without new resize listeners or shader renders. Actions appear on card hover or keyboard focus and remain accessible on touch devices. The timeline height and both sidebar widths remain adjustable. A sixth card action replaces only that step with a different random preset, preserving its asset assignment, timing and layer settings; the active editor updates when its selected step changes. Get Me Crazy, its whole-timeline shuffle, confirmation and restore state have been removed. Preset List no longer appears in the right chat column.

The release also includes the four-output asset library, faster library thumbnails and preservation of the mapped stage rectangle when replacing an image. Its reference aspect ratio survives project and mapping save/load. Existing automatic-generation preferences are retained, with new preferences initially off. Experimental shader video loops and the local automatic-enable migration are excluded.

Validation: 176 unit tests; ESLint; TypeScript and production build; secret scan; real WebGL2 and supported WebGL1 shader compilation. Browser checks cover desktop/mobile controls, lazy image previews, keyboard favorite/selection behavior, unchanged timeline thumbnails and stage bounds after an asset replacement, and shared custom-shader rendering/cache invalidation. Per-card random replacement also preserves other steps, the editor selection, the assigned asset and timeline duration. All 777 preset thumbnails generated successfully.
