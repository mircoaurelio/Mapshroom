# Static shader previews and studio cleanup

The preset library and shader timeline share static 128 × 128 WebP thumbnails on one flat square with a luminance gradient. Changing the stage asset no longer rebuilds thumbnails, and hovering a preset no longer changes or animates the stage. Explicit selection and timeline playback retain their existing behavior.

The packaged catalogue contains 777 presets backed by 763 unique images (2,547,914 bytes total). Identical shader code and effective uniform values share an image. Images load lazily and require no browser shader compilation. A representative frame is rendered at 1.6 seconds during generation; very dark presets retry at 3.2 and 5.6 seconds. WebP quality is 0.68. Regenerate with `npm run generate:thumbnails` after changing bundled presets; this requires Chrome, optionally selected with `CHROME_BIN`. Generation prunes obsolete images only after the complete replacement catalogue succeeds. Cache version 2 invalidates the previous sphere previews.

Custom shaders produce one frame per code/uniform combination on the same swatch. Generation is deferred until a card approaches the visible area, debounced during editing, serialized and shared across cards. Hidden/offscreen requests are deferred or cancelled. A bounded memory/CacheStorage cache holds up to 128 snapshots; the temporary WebGL renderer is released when the queue empties. Disabled storage falls back to session caching. Pending snapshots and image downloads show a small CSS loading icon until the actual image has loaded. Failed rendering or image loading shows a static unavailable icon; it never leaves a permanent spinner or a decorative radial placeholder. Reduced-motion preferences disable spinner animation.

The desktop chat, code and version history occupy the right sidebar in the upper workspace row. That column ends above the timeline, which spans the full width beneath both sidebars and the stage. The left sidebar retains sliders and asset controls. The existing mobile Shader drawer retains its compact prompt. There is no Shader Studio heading, manual Save control, suggestion tags or input-filling suggestion logic. Code starts collapsed and mounts the editor only when expanded; project autosave remains available. The desktop header exposes Projects through File and no longer duplicates the Projects button, its save-status badge or the Download/install button. The mobile Projects button is also a plain label without a save-status badge. Autosave status and retry remain in the Projects dialog.

The desktop timeline fills the complete workspace width below the stage and both sidebars. Its sole header contains previous/repeat/next, mode/count/duration, hold, transition settings and mode choices. The old position and segment rails, boundary/transition dragging, marker jumps and total-length scaling handlers have been removed, including their styles and listeners. The card highlight clock updates at 8 Hz while visible instead of a scrubber animation loop. Cards use square previews and plain text names, with no shader picker or redundant Shader label. The desktop timeline starts at 180 px, with cards about 105 px wide at a 1440 × 900 viewport. Narrow desktops reserve 200 px for the wrapped toolbar; compact spacing keeps the cards and scrollbar visible. Resizing starts from the rendered pane height so the responsive minimum does not cause a dead zone. Square flow nodes size from the actual scrollable height after subtracting the caption, including any horizontal scrollbar, without new resize listeners or shader renders. The 80 px minimum also fits narrow desktops with long sequences. New/Random uses the same card height as shader cards. The old proportional size reduction and full-height Add card no longer leave an empty band below the previews. Six action buttons share one row inside the square, one pixel from its top edge. The buttons scale down with the available width and stop at 20 px; their icons stop at 11 px. The toolbar shrinks from 22 px to about 12 px at the smallest card size and cannot wrap. Preview flex shrinking is disabled to preserve the square. The preview and caption form a native selection button; the action buttons are separate siblings, so activating a tool cannot also select the card. A 180 ms hover delay allows a quick click to select the preview before tools appear under the pointer. Keyboard focus reveals tools immediately and Tab moves from selection through the six actions; touch devices keep them visible. The timeline height and both sidebar widths remain adjustable. Disabled steps collapse to a 32 px vertical strip with a muted preview, a power icon and Off label; its height matches the desktop cards and is 80 px in the mobile drawer. Its sole interaction is Enable: editing, pinning, asset drops, random replacement, duplication, deletion and mobile dragging are not exposed on disabled cards. Enabling restores the full card without changing the focused/editor selection. Timed playback is reanchored to the same current shader and local phase, preserving shader animation time, including random order and focused repeat. Pending repeat exits are recalculated. The Now badge is removed; the current shader has a bright blue border and 2 px inset ring, also when selected for editing. Desktop and mobile highlights use the same random seed as the stage. Keyboard focus follows the disable/enable transition. The same compact restore-only card is used in the mobile Shader drawer. A sixth card action replaces only that step with a different random preset, preserving its asset assignment, timing and layer settings; the active editor updates when its selected step changes. Get Me Crazy, its whole-timeline shuffle, confirmation and restore state have been removed. Preset List no longer appears in the right chat column.

The release also includes the four-output asset library, faster library thumbnails and preservation of the mapped stage rectangle when replacing an image. Its reference aspect ratio survives project and mapping save/load. Existing automatic-generation preferences are retained, with new preferences initially off. Experimental shader video loops and the local automatic-enable migration are excluded.

Validation: 176 unit tests; ESLint; TypeScript and production build; secret scan; real WebGL2 and supported WebGL1 shader compilation. Browser checks cover desktop/mobile controls, lazy image previews, keyboard favorite/selection behavior, unchanged timeline thumbnails and stage bounds after an asset replacement, and shared custom-shader rendering/cache invalidation. Per-card random replacement also preserves other steps, the editor selection, the assigned asset and timeline duration. All 777 preset thumbnails generated successfully.
